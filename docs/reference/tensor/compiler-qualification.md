# Archived [qualification](../../glossary.md#term-qualification) reference

This former qualification inventory is historical, not a current capability reference. Use [current reference goals](../index.md) for supported workflows. Earlier detailed text is preserved in [the historical archive](../../history/reference/tensor/compiler-qualification.md).

## Reading the archived evidence

“Qualification” means evidence for a particular route, input domain and implementation revision,
not a promise that every Tensor expression can execute. The linked record preserves its original
claims. Start with [Tensor descriptions](descriptors.md) to separate construction from
execution, then consult the [current production support matrix](../../backend-guide/production-support.md).
