# Archived [qualification](../../glossary.md#term-qualification) reference

This former qualification inventory is historical, not a current capability reference. Use [current reference goals](../index.md) for supported workflows. Earlier detailed text is preserved in [the historical archive](../../history/reference/tensor/historical-status.md).

## Editorial reading context

The archived statuses describe what their authors had established at that time. An expression
constructor accepting descriptors is not the same event as a Compiler deriving gradients or a
backend executing values. Use [Tensor descriptions](descriptors.md) for the first boundary and
the [current support matrix](../../backend-guide/production-support.md) for qualified execution.
This navigation does not update the archived decisions or evidence.
