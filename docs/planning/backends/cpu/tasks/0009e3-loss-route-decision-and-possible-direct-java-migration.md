## Goal

Choose, separately for each current static CPU loss family, the route with demonstrably lower total implementation, verification, and retirement cost: retain bounded generated bytecode or migrate its static loops and orchestration to finite direct typed Java. This is a correctness and maintainability decision, not a performance campaign.

Preserve static Shapes; resolved non-negative layouts; type promotion/result narrowing; legal ordered role-to-unique-boundary aliasing for equal MSE/dense input roles; typed heap arrays, native-order `MemorySegment`s, and ordered mixed carriers; dense-linear/general-odometer access; checked span/address/range arithmetic; injective output writes; input-only aliasing; and output/input or output/output overlap rejection.

Preserve increasing element MSE subtraction/square; categorical increasing sample/class stable classification, shifted exponential, log-sum-exp, and contribution passes; dense zero-target exclusion before non-finite multiplication; index ignore-before-bounds-or-logits-read; left-associated `SUM`/`MEAN` accumulation and one final typed division. Preserve binary32/binary64 boundaries, special values, empty `NONE`, empty `SUM` positive zero, empty `MEAN` NaN, `C == 0`, all-ignored index domains, and index non-ignored-count mean.

Preserve independent scalar/caller-parallel `NONE` ranges; one complete ordered scalar range for `SUM`/`MEAN`; zero workspace; immutable prepared invocation; cold complete index validation before mutation/submission; and current fail-closed admission, lowering, binding, preparation, finalization, cache/artifact, publication, and no-write behavior. ## Route-selection decision rule

First establish that both candidates preserve the full family boundary. For each family record (1) retained-generation emitter/Class-File review, cold typed carrier/layout binding, validation, artifact/cache/inventory, invocation, oracle, and focused-evidence costs; (2) finite direct-Java implementation and cold selection/binding costs; and (3) complete generated-route retirement plus semantic, rejection, invocation, cache, inventory, oracle, and hot-loop verification costs. Select direct Java only when (2) plus (3) is demonstrably strictly lower than (1). This supplies no metric, benchmark, or performance conclusion.
