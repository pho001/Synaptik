and strides exactly equal to `LayoutDescriptor.contiguous(shape).strides()`, even with `isView=true`.

invariant roles, including independently qualified actual Compiler reverse seeds/saved/primal reads.

outputs/write boundaries remain non-view canonical; do not globally relax `canonical()`.

by `analyzePointwise` and `analyzeShaped`, with meaningful affected-contract Javadoc. Dense twins
must produce identical addresses, spans, accesses, resources, IR, keys and generated bytes.
Bounds, storage accessibility/capacity, overlap, lifetime and positional role proofs remain exact.

## Acceptance criteria

1. Actual provider accepts dense view reads for every declared role across pointwise/shaped/MATMUL
   F32/F64, forward and actual generated reverse; provider and lowering agree. Use representative
   focused cases, not a giant Cartesian matrix. Assert that the intended view reaches each boundary.
2. Canonical twins differing only in `isView` have equal access plans/bindings, referenced spans,
   geometry/resources, `CpuGeneralScanIr`, canonical and both specialization identities and class
   bytes; unchanged schema/family 71 and staged v4. No new stages, copies, CONTIGUOUS or normalization.
3. Real Conv1d-prefix → explicit Scan RNN equation forward AND actual Compiler reverse execute
   against independent ordinary unrolling in F32/F64. Check outputs and numeric gradients for
   recurrent W/U/b and trainable prefix/input targets where connected, using the same owned leaves.
   Include non-gradient zero h0 and non-square geometry; do not alter ModelBuilder `.rnn`.
4. A real singleton CONCAT on the Scan output creates the actual dense view reverse seed; execute
   its generated reverse and compare numeric gradients with ordinary unrolling. A fabricated
   backward body/provider-only assertion is insufficient for either source regression.
5. Preserve canonical formals/results (including dead ports/T=0); reject view-marked formals/writes,
   absent layout, nonzero offset and noncanonical-stride actuals, except already-supported all-zero
   scalar reads. Unsupported low/mixed types, body/role/budget failures still reject even dead/empty.
6. Retain scalar all-zero reads at zero offset, including rank-zero/expanded generated constants,
   missing seeds and scalar-to-dense carry transitions. Exercise T=0 and empty step domains where
   applicable without skipping nonempty SUM/MATMUL work. No canonical-singleton-stride shortcuts.
7. Heap and segment carriers, changed values across repeated reusable runs, legal repeated/read-read
   aliases and read-only inputs work. Short/inaccessible/misaligned storage and write/scratch overlap
   (including capacity tails)/read-only output reject before mutation; existing lifetime guards stay.
8. Generator/binding/identity stay unchanged. Reuse CPU0036's source-matched specialized optimal
   clean-Java/Class-File/performance evidence and limitations; twin byte equality supports reuse,
   not a new speed/parity claim. Stop for main if that premise fails.
