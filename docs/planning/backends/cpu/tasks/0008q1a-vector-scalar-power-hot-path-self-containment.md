# Task 0008Q1A: [Vector](../../../../glossary.md#term-vector) [Scalar](../../../../glossary.md#term-scalar)-Power Hot-Path Self-Containment

## Status

Complete

## Goal

Make every currently generated [FLOAT32](../../../../glossary.md#term-float32) and [FLOAT64](../../../../glossary.md#term-float64) [vector](../../../../glossary.md#term-vector) [scalar](../../../../glossary.md#term-scalar)-power [specialization](../../../../glossary.md#term-specialization) self-contained with respect to Synaptik production helpers. Emit the proved `POSITIVE_ONE`, [`IDENTITY`](../../../../glossary.md#term-identity-meanings), `SQUARE`, and `RECIPROCAL` realizations directly so each generated Class-File preserves the matching optimal clean Java specialization's semantic algorithm, vector-chunk and scalar-tail [dataflow](../../../../glossary.md#term-dataflow), and avoidable-overhead profile.

This is structural and performance remediation discovered while executing [CPU](../../../../glossary.md#term-cpu) 0008Q1. It does not require literal byte-for-byte Class-File identity or guarantee identical just-in-time [compiler](../../../../glossary.md#term-compiler) assembly.

## [Scope](../../../../glossary.md#term-scope)

- Replace the generated [vector](../../../../glossary.md#term-vector) `SCALAR_POW` calls to `CpuVectorMath` for `POSITIVE_ONE` and `RECIPROCAL` with direct typed Java [Vector API](../../../../glossary.md#term-vector-api) [bytecode](../../../../glossary.md#term-bytecode). Keep [`IDENTITY`](../../../../glossary.md#term-identity-meanings) as a direct value and `SQUARE` as one direct typed vector multiply, and test all four realizations under one [fail-closed](../../../../glossary.md#term-fail-closed) contract.
- Cover every currently generated vector [scalar](../../../../glossary.md#term-scalar)-power form for [FLOAT32](../../../../glossary.md#term-float32) and [FLOAT64](../../../../glossary.md#term-float64), including `VECTOR` and caller-parallel `PARALLEL_VECTOR` orchestration; primitive-array input/output, native-order [`MemorySegment`](../../../../glossary.md#term-memorysegment) input/output, and every currently admitted ordered mixed array/segment input/output [carrier](../../../../glossary.md#term-storage-carrier) pair; arbitrary legal ranges; complete vector chunks; and scalar tails.
- Cover standalone scalar-power occurrences and representative legal [fused](../../../../glossary.md#specialization-and-fusion) [pointwise](../../../../glossary.md#term-pointwise) occurrences whenever surrounding instructions change local/[dataflow](../../../../glossary.md#term-dataflow) [shape](../../../../glossary.md#shape). Derive the [finite](../../../../glossary.md#term-finite) form inventory from current [lowering](../../../../glossary.md#lowering), preparation, [specialization](../../../../glossary.md#term-specialization), and generation rather than only the first failing [CPU](../../../../glossary.md#term-cpu) 0008Q1 [fixture](../../../../glossary.md#term-fixture).
- Preserve exact represented [exponent](../../../../glossary.md#term-exponent) bits and `PowerRealization` identity. `DIRECT` remains vector-ineligible and uses the safe scalar or caller-parallel scalar fallback; no scalarization inside a vector body, [lane](../../../../glossary.md#term-lane)-wise `Math.pow`/`StrictMath.pow`, approximation, or new realization is allowed.
- Advance the current-only generator compatibility [schema](../../../../glossary.md#term-schema) exactly once after generated bytes change. Old [artifacts](../../../../glossary.md#term-artifact) are safe misses; do not add a migration reader or weaken specialization identity.
- Add semantic tests against independent typed optimal clean Java specializations for all affected realizations, types, carriers, ranges, vector chunks, and tails, including [NaN](../../../../glossary.md#term-nan) classification, [infinities](../../../../glossary.md#nan-infinity-and-signed-zero), [signed zero](../../../../glossary.md#term-signed-zero), [subnormals](../../../../glossary.md#term-subnormal), [overflow](../../../../glossary.md#term-overflow), and [underflow](../../../../glossary.md#term-underflow) where applicable.
- Add automated Class-File/[decompilation](../../../../glossary.md#term-decompilation) tests for direct [descriptors](../../../../glossary.md#term-descriptor), carrier access, vector loop and scalar-tail dataflow, exact allowed [JDK](../../../../glossary.md#term-java-development-kit-jdk) calls, and absence of Synaptik-owned hot-path calls, allocation, boxing, reflection, method handles, dynamic calls, maps, string [dispatch](../../../../glossary.md#term-dispatch), generic carrier branches, and avoidable virtual/interface dispatch.
- Produce proportionate generated-versus-direct performance evidence from fixed equivalent Java 26 specializations. Use a source-derived finite [matrix](../../../../glossary.md#term-matrix-meanings) covering both lane types, all four realizations, each distinct carrier-access code shape, vector chunks and tails, and both orchestration modes; project a timed row only when Class-File inspection proves the omitted [dimension](../../../../glossary.md#dimension) does not change the relevant hot body.
