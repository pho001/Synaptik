## Reader context

Read the task table as a delivery ledger, not as one timeless support matrix. A row's Complete
status records that task's bounded result; Blocked records its original qualification failure.
The later frontier and gates have a different purpose: identifying authorized work. Likewise,
protocol versions and device observations belong to their named checkpoints. None of the
representative operation counts proves every type, layout or derivative graph.

At the execution boundary, Planning selects the backend owner, Metal analysis fixes the physical
route, shared Prepare assigns storage positions, and Metal finalization creates reusable native
resources. Runtime then binds actual input buffers and invokes that fixed work. A Tensor's
descriptor describes its indexing and type; it is not the buffer containing its values.
The [current Metal lifecycle explanation](../../../explanation/packages/metal.md#purpose-callers-and-non-goals)
names these collaborators, while the [production support ledger](../../../backend-guide/production-support.md#metal-production-target)
separates present bounded qualification from the historical task outcomes below.

Maintain truthful [Metal](../../../glossary.md#term-metal) capability, [MPSGraph](../../../glossary.md#term-mpsgraph)/custom routes, native storage and resources across
cold preparation and [synchronous](../../../glossary.md#term-synchronous) execution. This is an implementation map, not a contract.
[ARCHITECTURE.md](../../../../ARCHITECTURE.md) and the incorporated
[backend contract](../../../architecture/contracts/backend-execution.md#metal-backend) are authoritative.

Required scoped headings for new work are [Concrete backend](../../../glossary.md#concrete-backend) [modules](../../../glossary.md#term-module), Metal [backend](../../../glossary.md#backend), Low-[precision](../../../glossary.md#term-precision)
capability evidence, Profile-free [backend capability](../../../glossary.md#backend-capability) and [identity](../../../glossary.md#term-identity-meanings), and the applicable [Prepare](../../../glossary.md#prepare)/[Run](../../../glossary.md#term-run)
[lifecycle](../../../glossary.md#lifecycle) headings in [runtime-prepare-engine](../../../architecture/contracts/runtime-prepare-engine.md)<span data-glossary-navigation="true"> ([runtime glossary](../../../glossary.md#term-runtime); [engine glossary](../../../glossary.md#term-engine))</span>.
The [backend guide](../../../backend-guide/metal-backend.md) and native README explain implementation.

The [first-release product target](../../production-release-goal.md#metal-target)<span data-glossary-navigation="true"> ([release glossary](../../../glossary.md#term-release); [target glossary](../../../glossary.md#term-target))</span> requires
production-supported Metal in v1, not an experimental or deferred backend. Freeze its actual
hardware-qualified support [matrix](../../../glossary.md#term-review-matrix) and verify native installation and supported consumer workflows

or authorize an implementation successor; Java [CPU](../../../glossary.md#term-cpu) [F64](../../../glossary.md#floating-point-precision-and-rounding) parity is not a Metal capability promise.
