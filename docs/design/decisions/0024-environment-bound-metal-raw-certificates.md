# ADR 0024: Environment-Bound Metal Raw-Route Certificates

## Status

Superseded — 2026-09-29 by
[ADR 0025](0025-custom-only-metal-low-precision.md).

This document retains the historical decision and evidence narrative. Its certificate store,
environment export, probes, and alternate low MPSGraph route are no longer active.

## Context

Metal has a complete custom-program implementation for every admitted BFLOAT16 and FLOAT16
occurrence. The custom route is therefore the safe baseline. MPSGraph can also preserve raw
sixteen-bit words for some non-arithmetic Shape/layout programs, but a framework route name does
not bind the device, operating system, toolchain, loaded framework and bridge bytes, compilation
options, or exact graph image. Generic sampling would not establish that identity or prevent a
stale result from silently enabling a different program.

Certificate schema 1 already freezes the required key fields. It previously had no active loader,
certificate corpus, or route effect. The native bridge was ABI 5 and had no way to report the exact
context environment that cold preparation would use.

## Decision

### Canonical no-accumulator identity

A non-arithmetic certificate key uses the literal `NONE` for `accumulator-dtype`. Numeric
accumulator names remain valid for arithmetic families. Empty strings, BOOL, and other sentinels
are invalid.

### Immutable context environment

Metal native ABI 6 adds
`synaptik_metal_context_certification_environment`. One live context returns a canonical six-line
record containing:

- the highest supported Apple GPU family;
- the exact Darwin OS build;
- the macOS SDK and loaded MPSGraph framework versions;
- host compiler, Xcode build, and Metal compiler versions; and
- explicit graph options, optimization level, synchronous compilation choice, and
  reduced-precision-fast-math setting.

Java hashes the exact caller-selected dylib immediately before loading and after context creation.
A changed file rejects construction. The immutable Java identity adds that digest and the canonical
capability-ledger hash. Preparation reads only this retained identity; it performs no later device,
filesystem, framework, or toolchain discovery.

### Atomic schema-one store

The bundled UTF-8 TSV store is parsed once when the context opens. Missing data, forbidden bytes,
unknown schema/family/route/enums, malformed or heterogeneous dtype tuples, a non-`NONE`
accumulator, detached domain/program or determinism hashes, duplicate keys, and oversize input
reject the complete store. A rejected store is empty for eligibility.

Lookup is exact complete-key equality. There is no prefix, nearest-environment, compatible-GPU,
program-family, stale-binary, or shape fallback. Accuracy `PASS` is required for eligibility.
Determinism remains reported independently and cannot turn an accuracy failure into a qualified
route.

### Narrow raw-preserving MPSGraph candidate

`CUSTOM_PROGRAM` remains the first candidate for every low partition. A second `MPSGRAPH`
candidate exists only for a homogeneous no-gradient BFLOAT16 or FLOAT16 partition composed solely
of:

- `RESHAPE`;
- simple `PERMUTE`;
- materializing `CONTIGUOUS`;
- `SLICE`;
- `CONCAT`; or
- `TILE`.

Boundary physical layouts must be non-empty, zero-offset, contiguous storage. The certificate key
contains the exact schema-19 MPSGraph program-image SHA-256, so a certificate covers one complete
static Shape/layout/value/node/feed/target/profile image rather than an operation name. External
offsets, holes, zero extents, mixed carriers, gradients, arithmetic, a different environment, and
an unlisted program remain custom-only.

The selected route is fixed during cold analysis before shared resource declarations escape.
Finalization and execution cannot retry, fall back, or replace it. A graph plan declares only feeds,
targets, and its address workspace; custom internal materializations do not leak into the graph
plan. Trace PREPARE metadata reports the final route and, for this certificate family, the schema,
exact key digest, accuracy status, and separate determinism record.

### Evidence and activation

The checked-in `backends/metal/evidence/0072` accuracy and determinism reports were generated by the
production ABI-6 bridge on the environment named in those reports. For both profiles and both low
carriers, the harness executes every one of the 65,536 raw words through each of the six listed
programs, poisons supplied targets, repeats each executable three times, and requires byte-exact
expected output and repeat identity. It separately exercises 257-word odd counts. Offset/hole and
zero-count boundaries remain ineligible rather than being generalized from the dense evidence.

Only after the base RESHAPE/PERMUTE/CONTIGUOUS matrix passed did the same run admit
SLICE/CONCAT/TILE rows. The active store contains only exhaustive program rows and binds the exact
evidence-file digests. The identity ledger activates certificate schema 1 and ABI 6 together.

### Positive and qualified-negative vendor-route closure

The active store contains exactly 24 positive raw-preserving MPSGraph certificates: six exact
schema-19 programs, two low carriers, and two profiles. Neither classic Metal Performance Shaders
(MPS) nor Metal Performance Primitives (MPP) is positively certified.

`native/metal-macos-arm64/qualify-low-precision-vendor-routes.sh` rebuilds and executes the
checked-in probes with the installed Xcode 27 SDK/toolchain and the exact packaged ABI-6 dylib. The
canonical `backends/metal/evidence/0072/vendor-route-qualification.tsv` binds that probe source,
dylib, capability ledger, GPU, OS, SDK/framework, compiler, and option identity. Every row has
qualification `REJECTED` and one stable reason.

The classic-MPS probe confirms `MPSSupportsMTLDevice`, executes one FLOAT16
`MPSCNNConvolution` over an actual `MPSImage`, and reads back
`MPSNNConvolutionAccumulatorPrecisionOptionFloat`. Those gates do not prove the complete exact
Shape/layout occurrence domain or the ADR-0023 family envelope. The installed public data-source
contract excludes BFLOAT16; the isolated runtime construction probe rejects it, and no public
BFLOAT16 accumulator guarantee exists.

The MPP probe compiles `matmul2d` and `convolution2d` for FLOAT16 and BFLOAT16 inputs with FLOAT32
destinations. The source requires `__HAVE_TENSOR__`, statically fixes `relaxed_precision=false`,
compiles with Metal language 4.0 and deployment target 26.2, links a metallib, and creates all four
pipelines on the named Apple GPU. Those successful availability gates still expose no public
internal-accumulator type. A low-input/FLOAT32-destination signature specifies the destination
element type, not FLOAT32 internal accumulation, so it cannot satisfy ADR 0023.

Qualified-negative evidence creates no candidate, route family, route wire, or certificate.
Classic MPS and MPP therefore remain custom-only, and their probe failures or missing guarantees
cannot trigger runtime fallback.

## Consequences

- The capability provider and planning ownership do not change; this is a backend-private
  prepare-time route decision.
- Custom execution remains complete and independently selectable for every qualified raw graph.
- Deleting, corrupting, or copying the store to another environment reduces candidates to custom;
  it does not make preparation or execution less safe.
- Rebuilding or resigning the dylib, changing OS/framework/toolchain/options, changing schema-19
  bytes, or changing the capability ledger requires new evidence and new exact certificate rows.
- The native ABI has fourteen exports. Existing export signatures, program/operation/attribute/type
  wires, and route wires remain unchanged.
- Runtime gains no certificate lookup, device query, timing, retry, or fallback work.

## Rejected alternatives

### Qualify by operation kind

Kind-only qualification loses Shape, layout, value table, feed/target ordering, profile, and exact
program bytes. Rejected.

### Match compatible or newer environments

The evidence does not prove monotonicity across GPU families, OS/framework builds, toolchains,
bridge bytes, or graph options. Rejected.

### Remove the custom candidate after certification

The certificate adds an eligible opaque route; it does not invalidate the complete safe baseline.
Rejected.

### Retry custom after a graph execution failure

That would change a prepared execution's implementation and failure contract on the hot path.
Rejected.

### Use determinism as an accuracy gate

Repeat identity and numerical/raw correctness answer different questions. Determinism remains
separate metadata. Rejected.
