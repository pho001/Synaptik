<threat_model>
T-09-03: Adding layout ABI v2 symbols could make existing dense Metal/CUDA execution fail on older local native libraries. Mitigation: `layoutAbiV2Supported` is false when symbols are absent, while `isAvailable()` and `supportsBufferBindings()` keep their existing meanings.
T-09-04: Capability reports could conflate runtime unavailability with layout ABI v2 absence. Mitigation: separate capability fields and stable capability codes report native library, graph ABI, buffer ABI, and layout ABI v2 independently.
</threat_model>
