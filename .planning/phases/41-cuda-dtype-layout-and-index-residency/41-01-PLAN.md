# Plan 41-01: CUDA DType Role And Residency Contract

**Phase:** 41 CUDA DType Layout And Index Residency
**Requirements:** CUDADTYPE-01
**Status:** Planned
**Wave:** 1

## Objective

Give CUDA a checked-in dtype role contract that can represent `BFLOAT16`, `BOOL`, and `INT32` residency roles needed by v1.6, while keeping unsupported native compute/output roles explicit.

## Tasks

<action>
Add a small CUDA dtype role policy under `src/main/java/backend/cuda/`.

Required records/enums:
- `CudaDTypeRole`: `COMPUTE_INPUT`, `COMPUTE_OUTPUT`, `INDEX_INPUT`, `PREDICATE_INPUT`, `RESIDENCY_ONLY`.
- `CudaDTypeRoleDecision`: `DataType dataType`, `CudaDTypeRole role`, `boolean supported`, `String reasonCode`, `String detail`.
- `CudaDTypeRolePolicy`: deterministic `decide(DataType, CudaDTypeRole)` and convenience methods for buffer input/output and index input checks.

Policy truth:
- `FLOAT32` is supported for compute input/output and residency.
- `INT32` is supported only for `INDEX_INPUT` and `RESIDENCY_ONLY`.
- `BOOL` is supported only for `PREDICATE_INPUT` and `RESIDENCY_ONLY`.
- `BFLOAT16` is supported only for `RESIDENCY_ONLY`.
- `FLOAT64` is unsupported for CUDA native roles.
</action>
<acceptance_criteria>
- New source contains exact reason codes `SUPPORTED`, `UNSUPPORTED_DTYPE`, `UNSUPPORTED_ROLE`, and `RESIDENCY_ONLY_NOT_COMPUTE`.
- There is no method whose name implies generic `supportsComputeDType(BFLOAT16|BOOL|INT32)`.
- Role decisions mention `dtype residency is not native dtype compute` in detail text or docs.
</acceptance_criteria>
</task>

## Success Criteria

- CUDADTYPE-01 has source-level role truth.

- Existing dense `FLOAT32` CUDA path behavior is unchanged.

## Threat Model

- **T41-01:** `INT32` index residency could be mistaken for generic CUDA `INT32` arithmetic.
  **Mitigation:** Role-specific policy and tests keep `INDEX_INPUT` separate from compute/output.
- **T41-02:** `BFLOAT16` residency evidence could be reported as native CUDA BF16 support.
  **Mitigation:** `RESIDENCY_ONLY_NOT_COMPUTE` reason code and capability report assertions.
