</objective>

<threat_model>
T-15-07: Benchmark reports could parse compact text instead of structured manifest data. Mitigation: add structured manifest fields to `BackendSelectionDecisionTrace` and JSON renderer before adding compact text rendering.
T-15-08: Run trace could duplicate full prepare-time manifests and drift from backend-selection evidence. Mitigation: run trace only includes `gpuLoweredRegionId`, backend, and runtime path attributes when available.
T-15-09: Existing synthetic traces could break due to constructor churn. Mitigation: preserve `BackendSelectionDecisionTrace` overloads and default manifest to null/empty for old call sites.
</threat_model>
