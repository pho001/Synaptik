<objective>
Construct `GpuLoweredRegionManifest` from shared accelerator lowering and expose it through selected Metal/CUDA partition plans.
</objective>

<source_audit>
GOAL: Turns the manifest model into actual lowering evidence for selected GPU regions.
REQ GPUDAG-01: Covered by manifest construction from `AcceleratorSubgraphSpec` and `AcceleratorDagSpec`.
REQ GPUDAG-02: Covered by populating original op, primitive, backend, assumption, fused summary, and region length fields from lowering context.
CONTEXT D-01, D-02, D-03, D-04, D-13, D-14, D-15, D-16 are implemented by this integration layer.
</source_audit>

<threat_model>
T-15-04: Manifest construction could duplicate or diverge from actual lowered DAG nodes. Mitigation: build primitive metadata directly from `AcceleratorDagSpec.nodes()` after the DAG is created.
T-15-05: CUDA and Metal could fork manifest semantics. Mitigation: both backends expose the same `GpuLoweredRegionManifest` contract and only use backend extension strings for backend-specific detail.
T-15-06: Specialized expansions such as `LOG_SOFTMAX` could lose source-op attribution. Mitigation: add tests where original node `LOG_SOFTMAX` maps to lowered primitives `SOFTMAX` and `LOG`.
</threat_model>
