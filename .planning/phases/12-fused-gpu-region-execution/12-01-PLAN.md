<objective>
Create the shared GPU compound pattern contract that names compound GPU intent, carries it beside the existing accelerator DAG, and rejects CPU `Operation.OpType.FUSED` explicitly for Metal/CUDA paths.
</objective>

<source_audit>
GOAL: Establishes the backend-neutral summary plus DAG contract that all later Phase 12 plans consume.
REQ GPUFUSE-03: Defines GPU fused region planning as backend-specific compound DAG execution independent from CPU fused ASM/vector internals.
REQ GPUFUSE-04: Defines stable reduction-adjacent and CPU-FUSED rejection vocabulary before reduction-adjacent closure.
D-01 through D-08: Covered by shared detector, summary, and explicit CPU `FUSED` rejection.
D-14 and D-18: Covered by backend-specific coverage matrix rows and stable reason-code assertions.
</source_audit>

<threat_model>
T-12-01: A GPU path might treat CPU `Operation.OpType.FUSED` as an executable GPU primitive. Mitigation: detector and matrix tests must assert `FUSED` rejects as `CPU_FUSED_OPERATION_UNSUPPORTED` or equivalent stable reason before any backend execution.
T-12-02: A pattern summary could become a shortcut that bypasses DAG legality. Mitigation: `GpuCompoundPatternDetector` consumes the already-built `AcceleratorDagSpec` and optional `AcceleratorMatMulSpec`; it does not replace `AcceleratorSubgraphLowerer` legality checks.
T-12-03: Metal and CUDA coverage could drift. Mitigation: coverage matrix tests assert both backends expose explicit rows for compound supported/rejected states.
</threat_model>
