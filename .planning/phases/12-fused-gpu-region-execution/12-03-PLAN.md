<objective>
Expose and verify representative Metal/CUDA `ELEMENTWISE_CHAIN` compound execution so supported chains run as one accelerator region with traceable compound metadata and no CPU materialization boundary between chain nodes.
</objective>

<source_audit>
GOAL: Delivers representative elementwise-chain fused GPU region execution and trace evidence.
REQ GPUFUSE-02: Metal and CUDA execute representative elementwise-chain fused GPU regions and preserve device-owned intermediate values through region execution.
REQ GPUFUSE-03: Uses accelerator prepared executables and run trace metadata, not CPU fused internals.
D-10, D-12, D-16, D-17, D-18: Covered by full-chain selection, one-step prepared execution assertions, and CPU materialization trace checks.
</source_audit>

<threat_model>
T-12-06: The chain may be represented as multiple accelerator steps, allowing CPU materialization between them. Mitigation: tests assert exactly one accelerator step covers `ADD -> RELU -> EXP` and interior nodes have `PartitionExecutionRole.INTERIOR`.
T-12-07: Runtime trace may omit compound details even when lowering selected the pattern. Mitigation: trace tests assert stable `gpuCompound*` attributes on the accelerator step.
T-12-08: Native buffer unavailability may route through tensor-array copies. Mitigation: native-buffer-capable tests assert no `CPU_CONSUMER` materialization between chain nodes; fallback remains visible in AUTO mode.
</threat_model>
