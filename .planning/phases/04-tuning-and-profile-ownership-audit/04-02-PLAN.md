<threat_model>
T-4-04: Invalid persisted accelerator buffer modes could silently downgrade to defaults and hide fallback/performance regressions. Mitigation: strict IO rejects invalid enum values with key-specific errors.
T-4-05: Unsupported profile schema could be loaded as a fallback profile and produce misleading benchmark/autotune results. Mitigation: strict IO rejects unsupported planner/persistence schema versions before execution.
T-4-06: Breaking all legacy profiles at once could block calibration migration. Mitigation: missing legacy fields may still use documented defaults; invalid present fields fail.
</threat_model>
