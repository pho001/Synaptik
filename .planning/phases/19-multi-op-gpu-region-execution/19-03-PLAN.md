<objective>
Integrate Phase 19 multi-op region metadata into prepared Metal/CUDA execution and run traces without forking the shared planning contract.
</objective>

<source_audit>
REQ GPUMULTI-01: Covered by prepared execution tests that carry multi-op manifests to runtime.
REQ GPUMULTI-02: Covered by runtime trace assertions that supported internals remain device-owned.
REQ GPUMULTI-03: Covered by Metal/CUDA preparers sharing planning metadata while using backend-specific executable classes.
CONTEXT D-10, D-11, D-13, and D-15 are implemented by trace and prepared executable integration.
</source_audit>

<threat_model>
T-19-05: Metal and CUDA could diverge by adding backend-specific planning metadata. Mitigation: carry `GpuLoweredRegionManifest` through shared `PreparedAcceleratorExecutable` SPI.
T-19-06: Trace could claim multi-op GPU execution while the runtime used tensor-array or CPU fallback. Mitigation: render execution path and fallback/materialization evidence beside region metrics.
</threat_model>
