<objective>
Protect Phase 19 internal device handoffs by preventing supported multi-op native-buffer paths from forcing CPU-readable prepared inputs inside the region.
</objective>

<source_audit>
REQ GPUMULTI-02: Covered by runtime tests and executor changes that keep supported interiors device-owned through `ExecutionState` and device buffer bindings.
CONTEXT D-04, D-05, D-06, D-13, and D-15 are translated into materialization guards and trace evidence.
</source_audit>

<threat_model>
T-19-03: CPU fallback prepared-input logic could materialize supported GPU-region interiors and hide the CPU exit. Mitigation: detect supported native-buffer paths and assert no `ACCELERATOR_PREPARED_INPUT` materialization for interiors.
T-19-04: Fixing native buffer flow could break CPU fallback parity. Mitigation: preserve explicit fallback execution and require tests for both buffer and fallback paths.
</threat_model>
