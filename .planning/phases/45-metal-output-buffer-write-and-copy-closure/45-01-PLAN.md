# 45-01 Output Buffer Write Proof Harness

## Objective

Add a native no-copy MPSGraph buffer execution probe and tests that can prove whether caller-provided output buffers are written directly before the shim performs its explicit `readBytes` result copy.

## Tasks

1. Add an optional native symbol that executes the existing MPSGraph buffer path with caller output buffers but skips the final result-copy loop.
2. Add a concrete Java bridge probe method guarded by optional-symbol discovery.
3. Add sentinel tests that initialize the output buffer to known bytes, run the no-copy probe, then read the buffer through the allocator.
4. Keep normal `executeBuffers(...)` classified as `MPSGRAPH_RESULT_COPY` unless the proof is strong enough to update the execution path.

## Verification

- `./gradlew test --tests backend.metal.bridge.MetalMpsFfmBridgeTest`
- `./gradlew metalTest`
- `git diff --check`

## Completion Criteria

- The test suite can distinguish explicit native result copy from true caller-output writes.
- MPSGraph does not inherit the Phase 44 custom-kernel `TRUE_OUTPUT_BUFFER_WRITE` claim.
