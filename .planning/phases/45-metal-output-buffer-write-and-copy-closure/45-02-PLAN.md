# 45-02 Lower-Copy Or Alias Strategy

## Objective

Use the proof result from 45-01 to either enable a scoped true-write path or keep MPSGraph on explicit copy while reducing avoidable copies through route-specific alias/copy policy.

## Tasks

1. If the probe proves true writes for a scoped family, add a scoped policy that can skip the explicit native result copy only for that family.
2. If the probe does not prove true writes, keep MPSGraph on `MPSGRAPH_RESULT_COPY` and document why custom kernels remain the true-write route.
3. Ensure tensor-array path, buffer path, custom route, and CPU fallback each report distinct copy behavior.
4. Preserve public tensor semantics and graph-output materialization behavior.

## Verification

- Focused Metal bridge and prepared-execution buffer tests.
- Coverage summary tests for copy strategy counts.

## Completion Criteria

- No false zero-copy claim.
- Any copy reduction is route- and proof-scoped.
