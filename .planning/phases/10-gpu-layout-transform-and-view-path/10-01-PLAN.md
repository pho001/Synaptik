<objective>
Create the backend-neutral GPU layout transform/request/decision contract that later Metal and CUDA runtime paths can consume for metadata-only views and dense GPU materialization without exposing device residency through the public Tensor API.
</objective>

<source_audit>
GOAL: Covers the shared request/decision half of Phase 10.
REQ GPUVIEW-01: Covered by records for reshape, permute, expand, contiguous, alias/view-like values.
REQ GPUVIEW-03: Covered by backend-neutral records and stable reason codes; backend native handles remain backend-owned.
</source_audit>

<threat_model>
T-10-01: Layout transform decisions could silently hide CPU fallback or conflate metadata-only views with dense materialization. Mitigation: add explicit transform kinds, stable reason codes, and planner tests for every supported/rejected category.
T-10-02: Shared records could expose Metal/CUDA native handles. Mitigation: request records carry only `DeviceBufferBinding` interface metadata and opaque native handle identity through existing contracts.
</threat_model>
