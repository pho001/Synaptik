<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Runtime tensor metadata -> accelerator layout ABI | Mutable runtime tensor layout facts become backend-neutral buffer metadata consumed by native-capable backends. |
| Backend binding -> ExecutionState | Backend-specific binding objects cross into shared per-run runtime state through `DeviceBufferBinding`. |
| Native handle diagnostics -> common ABI | Backend-native handle identity is represented as a diagnostic token, not as an executable common handle. |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-001-01-01 | Tampering | `AcceleratorBufferLayout` constructor | mitigate | Validate non-null dtype/shape/strides/class, shape-stride length equality, non-negative offset/count/bytes, and defensive-copy arrays. |
| T-001-01-02 | Information Disclosure | `DeviceBufferBinding.nativeHandleIdentity()` | mitigate | Expose only backend-owned diagnostic identity strings; prohibit common imports of Metal/CUDA handle or FFM classes. |
| T-001-01-03 | Denial of Service | `logicalByteLength` calculation | mitigate | Use checked multiplication for logical element count times dtype byte size in `AcceleratorBufferLayout.of(...)`. |
| T-001-01-04 | Repudiation | `AcceleratorBufferReasonCode` | mitigate | Append stable reason codes and preserve existing names so traces/tests can identify fallback causes consistently. |
</threat_model>
