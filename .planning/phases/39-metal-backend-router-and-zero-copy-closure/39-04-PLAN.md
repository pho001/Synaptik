# Plan 39-04: Final Coverage Regression And Milestone Audit Readiness

**Phase:** 39 Metal Backend Router And Zero-Copy Closure
**Requirements:** METALROUTER-01, METALROUTER-02, METALROUTER-03
**Status:** Planned
**Wave:** 4
**Depends on:** 39-02, 39-03

## Objective

Close v1.5 with route-aware coverage reports, regression gates, documentation, and verification evidence that every Metal support claim is audit-readable.

## Tasks

1. Extend coverage summaries and target gates with route-aware fields:
   - selected Metal route counts
   - rejected route reason counts
   - native copy strategy counts
   - unexpected tensor-array replay
   - unexpected CPU fallback
   - shortened selected region
   - unexpected native-copy regression
2. Update benchmark text/JSON reports to show route/copy evidence at both workload and suite levels.
3. Add or update hot-path gate expectations for representative v1.5 workloads:
   - transformer block
   - masked SDPA
   - dense loss training
   - conv/pool
   - gather/take
   - bool compare/where
   - layout repair
4. Write `39-VERIFICATION.md` mapping `METALROUTER-01..03` to code, tests, reports, docs, and residual scope.
5. Update milestone docs so v1.5 audit can verify:
   - supported paths stayed on Metal;
   - unsupported paths exposed stable reasons;
   - MPSGraph/custom-kernel/CPU route decisions were report-visible;
   - native copy evidence is not confused with Java copy-back;
   - local profile artifacts remain unstaged.

## Acceptance Criteria

- `GpuCoverageSummary` or companion report objects expose route and native-copy evidence.
- `targetCoverageGates` fail hidden CPU fallback, tensor-array replay, shorter selected regions, and unexpected native-copy strategy regressions.
- `docs/metal-backend.md`, `docs/gpu-lowering-coverage.md`, and `docs/troubleshooting.md` explain the Phase 39 router/copy contract.
- `.planning/phases/39-metal-backend-router-and-zero-copy-closure/39-VERIFICATION.md` exists and marks all `METALROUTER-*` requirements.
- `git status --short` shows no staged or committed local tuning/profile artifacts.
