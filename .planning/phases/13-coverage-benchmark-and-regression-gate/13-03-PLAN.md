<objective>
Add fail-fast GPU coverage regression gates that turn the Phase 13 report contract into automated failures for lost coverage, unexpected CPU materialization, hidden tensor-array fallback, and unexpected device handoffs.
</objective>

<source_audit>
GOAL: Prevent hidden CPU exits after coverage metrics exist and representative workload baselines are available.
REQ GPUCOV-02: Covered by applying gates to representative coverage summaries.
REQ GPUCOV-03: Covered by fail-fast gate policy/result classes and regression tests.
D-07 through D-09: Covered by portable Java tests and capability-gated native framing.
</source_audit>

<threat_model>
T-13-08: A supported target workload could lose GPU coverage while tests still pass due to fallback success. Mitigation: gate fails with `lost GPU coverage`.
T-13-09: A new CPU materialization boundary could be introduced but hidden by correct final tensor values. Mitigation: gate fails with `unexpected CPU materialization`.
T-13-10: Tensor-array fallback could masquerade as accelerator coverage. Mitigation: gate fails with `hidden tensor-array fallback` when native buffer coverage is required.
</threat_model>
