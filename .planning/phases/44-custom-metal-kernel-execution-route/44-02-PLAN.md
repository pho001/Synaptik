# Plan 44-02: First Scoped Custom Kernel Execution

**Phase:** 44 Custom Metal Kernel Execution Route
**Requirements:** METALKERNEL-01, METALKERNEL-02
**Status:** Planned
**Wave:** 2

## Objective

Implement a real native custom Metal kernel for one scoped dense `FLOAT32` operation family and execute it through buffer bindings.

## Tasks

1. Add native custom-kernel compile/execution functions to the Apple Metal shim.
2. Implement the first scoped kernel as dense `FLOAT32` `RELU` or equivalent single-node unary elementwise route.
3. Extend the Java bridge with custom-kernel capability and execute methods.
4. Execute the selected custom route inside `PreparedMetalExecutable` only when route decision is `CUSTOM_KERNEL`.
5. Add capability-gated native tests proving output parity and no CPU/tensor-array replay for the scoped path.

## Acceptance Criteria

- At least one custom Metal kernel executes through the native bridge.
- CPU parity is tested for the scoped operation.
- Unsupported custom-kernel candidates fall back to MPSGraph or visible fallback without false support.

## Threat Model

- **T44-02:** Native custom kernel writes incorrect output or stale buffers.
  **Mitigation:** Parity tests must verify output values and runtime device buffer currentness after execution.
