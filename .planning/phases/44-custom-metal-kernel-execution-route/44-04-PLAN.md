Close Phase 44 with docs, verification artifacts, and hard gates that make custom-kernel scope reviewable and prevent route overclaims.

1. Document the scoped custom-kernel operation family and unsupported cases.
2. Document fallback behavior when the custom route is unavailable or ineligible.
3. Add `44-01-SUMMARY.md` through `44-04-SUMMARY.md` and `44-VERIFICATION.md`.

5. Run focused Java tests, native Metal test if available, `./gradlew classes`, and `git diff --check`.

## Acceptance Criteria

- Every `METALKERNEL` requirement maps to source, tests, docs, and verification evidence.
