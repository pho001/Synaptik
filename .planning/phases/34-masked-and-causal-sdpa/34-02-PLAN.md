# Plan 34-02: Mask Conversion Lowering And Native Execution

**Phase:** 34 Masked And Causal SDPA
**Requirements:** METALSDPAMASK-01, METALSDPAMASK-02
**Status:** Planned
**Wave:** 2

## Objective

Add executable Metal support for scoped external/effective `BOOL` mask direct SDPA by converting public mask semantics to backend score masking before softmax, without CPU materialization between query/key/value/mask and the Metal region.

## Tasks

1. Extend the accelerator DAG or SDPA node metadata so direct SDPA can carry an optional mask input and mask mode without reusing unmasked executable signatures.
2. Update `AcceleratorSubgraphLowerer` to lower direct masked SDPA only when Wave 1 legality approves dense `FLOAT32` Q/K/V/output and dense legal `BOOL` mask input.
3. Update `MetalMpsCapabilities` external input role logic so SDPA input 3 accepts `BOOL` only for the verified masked SDPA path.
4. Implement native MPSGraph masked SDPA:
   - compute scores,
   - apply scale in the CPU-compatible order,
   - convert `BOOL` mask to score exclusion with correct polarity,
   - softmax,
   - multiply by value.
5. Add Java/FFM/native parity tests for rank-3 and rank-4 external mask cases.
6. Preserve explicit rejection for unsupported mask layouts/dtypes and CUDA direct masked SDPA.

## Acceptance Criteria

- Supported external/effective BOOL masked direct SDPA executes through Metal buffer binding with CPU parity.
- Trace/lowering manifest evidence identifies masked SDPA and mask handling.
- Native signatures distinguish masked and unmasked SDPA.
- Unsupported mask cases fail with stable reason codes before tensor-array or CPU fallback in REQUIRE mode.

## Threat Model

- **Threat:** Mask polarity inversion passes symmetric fixtures.
  **Mitigation:** Use asymmetric value tensors and masks where the wrong polarity produces visibly different output.
- **Threat:** BOOL mask storage is copied through CPU before execution.
  **Mitigation:** REQUIRE-mode tests assert native buffer binding evidence and no `CPU_CONSUMER` materialization.
