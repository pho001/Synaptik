    Create `src/main/native/cuda/synaptik_cuda_graph_stub.cu`.

    Export these C ABI functions with exactly these names:
    - `int synaptik_cuda_graph_available(void)`
    - `const char* synaptik_cuda_graph_unavailable_reason(void)`
    - `void* synaptik_cuda_graph_create_context(void)`
    - `void* synaptik_cuda_graph_compile_partition_f32(void* context, int externalInputCount, const int* externalInputRanks, const int* externalInputDTypes, const int* externalInputDim0, const int* externalInputDim1, const int* externalInputDim2, const int* externalInputDim3, int nodeCount, const int* nodeTypes, const int* input0Kinds, const int* input0Indices, const int* input1Kinds, const int* input1Indices, const int* input2Kinds, const int* input2Indices, const int* input3Kinds, const int* input3Indices, const float* scalarValues, const int* outputRanks, const int* outputDim0, const int* outputDim1, const int* outputDim2, const int* outputDim3, int outputCount, const int* outputNodeIndices)`
    - `int synaptik_cuda_graph_execute_partition_f32(void* context, void* executable, const float** externalInputs, int externalInputCount, float** outputs, int outputCount)`
    - `void synaptik_cuda_graph_destroy_context(void* context)`
    - `void synaptik_cuda_graph_destroy_executable(void* executable)`

    Implement a minimal runtime probe:
    - include `<cuda_runtime_api.h>`
    - call `cudaGetDeviceCount(&count)` inside the availability path
    - return available only when the CUDA runtime call succeeds and `count > 0`
    - store a stable C string reason such as `CUDA runtime unavailable`, `CUDA device count is zero`, or `CUDA runtime probe failed: <cudaGetErrorString(status)>`
    - `create_context` returns `nullptr` when unavailable and otherwise returns a small heap-owned context struct
    - `compile_partition_f32` validates non-null context, `nodeCount > 0`, and `outputCount > 0`, then returns a heap-owned executable stub
    - `execute_partition_f32` returns nonzero for unsupported execution rather than writing invalid output
    - destroy functions tolerate null pointers

    Do not implement broad CUDA operations, device-buffer allocation, materialization, or adjacent handoff in this plan.
  </action>
