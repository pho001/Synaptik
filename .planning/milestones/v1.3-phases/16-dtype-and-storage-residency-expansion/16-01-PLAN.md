<objective>
Add runtime typed slot binding for `BFLOAT16`, `INT32`, and `BOOL` while preserving existing alias, workspace, and floating dtype behavior.
</objective>

<source_audit>
GOAL: Expands storage residency where non-FLOAT32/FLOAT64 region slots currently no-op.
REQ GPUSTORAGE-01: Covered by dtype-specific reusable region slot maps and binding calls.
REQ GPUSTORAGE-03: Covered by focused runtime binding tests and CPU parity at true execution output.
CONTEXT D-01, D-02, D-03, D-12, and D-13 are implemented in this wave.
</source_audit>

<threat_model>
T-16-01: Typed slot binding could mutate public `Tensor` semantics or introduce device APIs. Mitigation: use existing logical `Tensor.setData(short[]/int[]/byte[])` APIs only inside `RuntimeMemoryBinder`.
T-16-05: Slot reuse could corrupt aliases or workspace-sensitive tensors. Mitigation: keep existing alias/view skip and runtime binding policy checks unchanged; add regression tests.
</threat_model>
