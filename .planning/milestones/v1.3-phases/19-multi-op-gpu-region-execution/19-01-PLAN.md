<objective>
Lock the Phase 19 multi-op lowered-region contract so supported Metal/CUDA partitions remain one backend-owned graph region while unsupported internals reject before runtime execution.
</objective>

<source_audit>
REQ GPUMULTI-01: Covered by lowerer tests that create selected regions with multiple original operations and multiple lowered primitives.
REQ GPUMULTI-03: Covered by symmetric Metal/CUDA lowerer behavior over the shared `GpuLoweredRegionManifest`.
CONTEXT D-01 through D-03, D-07 through D-12 are translated into concrete lowerer and manifest checks.
</source_audit>

<threat_model>
T-19-01: A selected GPU partition could be decomposed into Java-visible per-op execution steps, reintroducing CPU boundaries. Mitigation: assert one lowered region/unit for supported multi-op candidates.
T-19-02: Unsupported internal primitives could execute CPU work inside a GPU region. Mitigation: require candidate shortening/rejection metadata before execution.
</threat_model>
