<objective>
Enable supported elementwise chains inside selected GPU regions to be represented and executed as region-internal fused subpatterns.
</objective>

<source_audit>
REQ GPUFUSEX-01: Covered by optimizer/lowerer/runtime tests for `ADD -> RELU -> EXP` and mixed-region elementwise subchains.
REQ GPUFUSEX-03: Covered by detector/source hygiene tests that reject CPU `Operation.OpType.FUSED`.
RESEARCH: Existing `GenericGpuRegionOptimizationPolicy` only fuses a whole GPU partition when all nodes are fusable; Phase 18 needs safe subchains inside larger GPU regions.
</source_audit>

<threat_model>
T-18-03: Elementwise subchain fusion could shorten a selected GPU region and inflate coverage. Mitigation: region tests assert selected region node ids are unchanged and subpattern metadata is internal.
T-18-04: AUTO-mode CPU fallback could be mistaken for successful fused GPU execution. Mitigation: REQUIRED-mode tests assert failures are visible before hidden fallback, and buffer-binding traces must show no CPU-consumer materialization for fused interiors.
</threat_model>
