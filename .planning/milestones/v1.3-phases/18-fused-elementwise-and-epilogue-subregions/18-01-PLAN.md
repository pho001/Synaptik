</objective>

<source_audit>
GOAL: Add region-internal GPU fusion for elementwise chains and linear/matmul epilogues without reusing CPU fused ASM nodes.
REQ GPUFUSEX-01: Covered by metadata for supported elementwise chain subpatterns.
REQ GPUFUSEX-02: Covered by metadata for supported matmul/linear epilogue subpatterns.
REQ GPUFUSEX-03: Covered by explicit CPU `Operation.OpType.FUSED` rejection and source hygiene guardrails.
RESEARCH: Phase 18 requires richer list-capable subpattern metadata beside the existing single `GpuCompoundRegionSummary`.
</source_audit>

<threat_model>
T-18-01: The metadata model could accidentally become a GPU public operation model. Mitigation: place new records under `backend.accelerator.lowering` and keep public `tensor.Tensor` unchanged.
T-18-02: GPU fusion could reuse CPU fused ASM internals through imports or `Operation.OpType.FUSED`. Mitigation: keep CPU `FUSED` rejected in detector/matrix docs and add source hygiene assertions.
</threat_model>
