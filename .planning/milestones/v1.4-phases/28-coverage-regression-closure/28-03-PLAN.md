# Plan 28-03: Final Coverage Report Evidence

**Phase:** 28 Coverage Regression Closure
**Requirements:** GPUCLOSE-01, GPUCLOSE-03
**Status:** Planned
**Wave:** 3
**Depends on:** 28-01, 28-02

## Objective

Produce auditable final coverage evidence for v1.4 that shows before/after fallback reduction, target gate status, native evidence, capability skips, and residual unsupported blockers without relying on local benchmark timing artifacts.

## Tasks

1. Extend deterministic report tests, if needed, so text and JSON outputs include all Phase 28 audit fields:
   - target workload name,
   - backend,
   - gate pass/fail,
   - native evidence status,
   - capability skipped status,
   - selected region length,
   - lowered primitive count,
   - buffer-binding/tensor-array/CPU-fallback counts,
   - CPU materialization count,
   - device handoff count,
   - visible reason codes for unsupported targets.
2. Use `GpuCoverageBaseline` / `GpuCoverageComparison` or an equivalent checked-in deterministic fixture to render before/after coverage deltas for v1.4 target families without raw latency thresholds.
3. Add tests proving final report rendering does not treat local profile/calibration paths as canonical evidence.
4. Update docs:
   - `docs/gpu-lowering-coverage.md`,
   - `docs/compute-flow.md`,
   - `docs/calibration-autotune.md` if artifact hygiene wording needs tightening,
   - `docs/testing.md` if focused gate commands change.
5. Record final evidence in Phase 28 summaries without committing local `profiles/platform/...` benchmark outputs.

## Acceptance Criteria

- Text and JSON reports expose target coverage gates and native evidence for all Phase 28 targets.
- Before/after comparison is deterministic and based on coverage counters, not timing medians.
- Unsupported residuals remain visible as capability/reason evidence and do not count as native closure.
- Docs tell reviewers exactly which fields prove "hot path stayed on GPU."

## Threat Model

- **Threat:** Timing-only benchmark output is mistaken for coverage proof.
  **Mitigation:** Final evidence uses trace-derived coverage counters and deterministic renderer tests.
- **Threat:** Local profile artifacts are accidentally promoted as benchmark proof.
  **Mitigation:** Artifact hygiene remains an explicit validation and summary gate.
