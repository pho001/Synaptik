## Objective

Make the full Phase 27 conv/pool and BOOL compare surface explicit in the shared Metal/CUDA coverage matrix and semantics contracts.

- Add coverage rows for all conv/pool forward, backward, and lowered GEMM operation types.

- Update semantics contracts to cover logical BOOL ops, BOOL reductions, and conv/pool variants.
- Add tests proving no Phase 27 target silently falls through to generic `UNSUPPORTED_OPERATION`.
