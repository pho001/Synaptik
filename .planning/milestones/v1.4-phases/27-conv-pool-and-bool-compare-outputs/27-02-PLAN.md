# 27-02 Bool Compare Output Residency And WHERE Boundary Evidence

## Objective

Prove the current BOOL output state honestly: external BOOL predicate residency exists for `WHERE`, but BOOL-producing compare/logical/reduction nodes are not yet native GPU compute outputs.

## Tasks

- Add planner diagnostics for representative compare/logical BOOL nodes.
- Add tests proving compare-to-`WHERE` currently materializes or falls back visibly rather than silently claiming GPU support.
- Document that supported BOOL output compute requires a future DAG/native ABI extension.

- Metal/CUDA planner tests expose stable `UNSUPPORTED_DTYPE` reasons for BOOL-producing nodes.
