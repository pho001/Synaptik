# Plan 23-01: Shared Forward Reduction DAG Contract

**Phase:** 23 Forward Reductions Native Execution
**Requirements:** GPURED-01
**Status:** Complete

## Objective

Add backend-neutral DAG representation and lowering for `SUM`, `MEAN`, `REDUCE_MIN`, and `REDUCE_MAX`.

## Tasks

1. Add `SUM`, `MEAN`, `REDUCE_MIN`, and `REDUCE_MAX` node types with stable ABI codes.
2. Lower reduction descriptors into DAG nodes with encoded axis/keep-dims metadata.
3. Mark forward reduction matrix rows supported for Metal/CUDA only after lowerer coverage exists.
4. Update target truth rows to classify reductions as native-executable targets for the v1.4 scope.
5. Add focused lowerer/matrix tests for axis and keep-dims metadata.

## Acceptance Criteria

- Lowered DAG for each forward reduction carries the correct primitive type and scalar metadata.
- Existing unsupported normalization/loss/index/conv/BOOL rows remain unsupported or fallback.
- Tests fail if reductions are reported supported by matrix but not native-executable truth rows.
