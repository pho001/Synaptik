# Plan 23-02: Metal And CUDA Native Reduction Execution

**Phase:** 23 Forward Reductions Native Execution
**Requirements:** GPURED-02, GPURED-03
**Status:** Complete

## Objective

Implement backend execution for supported forward reductions.

## Tasks

1. Add Metal MPSGraph cases for `SUM`, `MEAN`, `REDUCE_MIN`, and `REDUCE_MAX`.
2. Add CUDA native buffer reduction kernels for rank 1-4 dense FLOAT32 reductions.
3. Keep tensor-array/CPU fallback visible when native bridge capability is unavailable.
4. Add native or capability-gated tests for Metal/CUDA reduction execution.

## Acceptance Criteria

- Metal native shim can compile and execute a simple reduction plan.
- CUDA native shim has reduction kernels and explicit reason strings for unsupported execution cases.
- Java-side execution still materializes graph outputs only at true output/consumer boundaries.
