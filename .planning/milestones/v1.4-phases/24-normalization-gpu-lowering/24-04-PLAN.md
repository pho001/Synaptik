# Plan 24-04: Normalization Parity And Coverage Closure

**Phase:** 24 Normalization GPU Lowering
**Requirements:** GPUNORMX-02, GPUNORMX-03
**Status:** Planned
**Wave:** 4
**Depends on:** 24-01, 24-02, 24-03

## Objective

Prove legal normalization hot paths stay on GPU and match CPU output parity while keeping local benchmark/profile artifacts out of committed evidence.

## Tasks

1. Add focused CPU parity tests for selected GPU normalization:
   - layer norm `[2, 3]` with gamma/beta `[3]`,
   - RMS norm `[2, 3]` with gamma `[3]`,
   - multi-axis layer norm `[2, 4, 8, 1]` with gamma/beta `[8, 1]`.
2. Add prepare/trace tests proving selected normalization regions use `PreparedMetalExecutable` or `PreparedCudaExecutable` for legal FLOAT32 cases.
3. Add materialization trace assertions:
   - no CPU materialization between region-internal normalization primitives,
   - graph-output materialization remains visible when public CPU data is read,
   - CPU consumer materialization remains visible when a later CPU op consumes a normalization output.
4. Update coverage hot-path expectations for `layer_norm_small` and `rms_norm_small` from blocker-only partial policies to supported normalization coverage for legal backends.
5. Run focused workload/report tests and record evidence in summary without committing local profile artifacts.

## Acceptance Criteria

- `PreparedExecutionBuildTest` has positive selected-GPU tests for both `LAYER_NORM` and `RMS_NORM`.
- `GpuHotPathCoverageTargetsTest` or `GpuCoverageRegressionGateTest` asserts normalization hot-path expectations no longer list `REDUCTION_ADJACENT` as the legal-case blocker.
- CPU parity checks compare normalized outputs within a documented FLOAT32 tolerance.
- `git status --short profiles/platform` shows no newly staged profile/calibration files from this phase.

## Threat Model

- **Threat:** Passing tests only prove planner selection, not value correctness.
  **Mitigation:** Include output parity tests against CPU results.
- **Threat:** Local benchmark profiles are accidentally treated as canonical phase evidence.
  **Mitigation:** Summary records profile hygiene and no profile artifacts are staged.
