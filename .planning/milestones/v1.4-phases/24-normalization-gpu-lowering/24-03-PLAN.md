# Plan 24-03: Planner Admission And Coverage Matrix Update

**Phase:** 24 Normalization GPU Lowering
**Requirements:** GPUNORMX-01, GPUNORMX-02, GPUNORMX-03
**Status:** Planned
**Wave:** 3
**Depends on:** 24-01, 24-02

## Objective

Move legal `LAYER_NORM` and `RMS_NORM` cases from visible fallback to supported Metal/CUDA GPU lowering while preserving explicit rejections for unsupported cases.

## Tasks

1. Update `GpuLoweringCoverageMatrix` rows for `LAYER_NORM` and `RMS_NORM` to `SUPPORTED` for Metal and CUDA only after 24-01 and 24-02 execution support exists.
2. Update `GpuTargetCoverageTruth` so legal normalization rows classify as native-executable/lowered GPU execution, not fallback-only evidence.
3. Update `MetalPartitionSupport` and `CudaGpuRegionLegalityAdapter`:
   - return empty planner unsupported reason for legal dense `FLOAT32` normalization,
   - reject unsupported dtype with `UNSUPPORTED_DTYPE`,
   - reject direct unsupported non-dense layout with `UNSUPPORTED_LAYOUT`,
   - reject invalid rank/shape with `UNSUPPORTED_RANK_OR_SHAPE`,
   - keep CPU fused `Operation.OpType.FUSED` isolation unchanged.
4. Update tests that currently assert `DEFERRED_FUSED_REGION` for normalization:
   - `MetalRegionLowererTest`
   - `CudaRegionLowererTest`
   - `PreparedExecutionBuildTest`
   - `CompiledGraphTraceTest`
   - `GpuCoverageSummaryTest`
   - `BenchmarkSessionTest`
5. Update docs in `docs/gpu-lowering-coverage.md` to mark normalization supported for legal cases and list remaining unsupported variants.

## Acceptance Criteria

- `GpuLoweringCoverageMatrixTest` asserts `LAYER_NORM` and `RMS_NORM` are supported for Metal and CUDA.
- Legal FLOAT32 normalization planner reasons are empty strings for both backends.
- Unsupported BFLOAT16 or unsupported layout normalization still has explicit stable rejection text.
- Docs no longer say normalization remains fallback for the supported legal case.

## Verification

```bash
./gradlew test --tests backend.accelerator.lowering.GpuLoweringCoverageMatrixTest --tests backend.metal.lowering.MetalRegionLowererTest --tests backend.cuda.lowering.CudaRegionLowererTest --tests GpuCoverageSummaryTest --tests CompiledGraphTraceTest
```

## Must Haves

- GPUNORMX-01: planner admits legal normalization GPU regions.
- GPUNORMX-02: unsupported dtype/layout/rank variants reject explicitly.
- GPUNORMX-03: coverage evidence stops treating normalization as a blocker for legal hot paths.

## Threat Model

- **Threat:** Updating matrix rows before native execution creates false coverage.
  **Mitigation:** This plan depends on 24-02 and test updates assert executable metadata, not only matrix values.
- **Threat:** Stable rejection vocabulary regresses.
  **Mitigation:** Keep explicit tests for unsupported dtype/layout/rank cases.
