# Plan 24-01: Shared Normalization DAG Contract

**Phase:** 24 Normalization GPU Lowering
**Requirements:** GPUNORMX-01, GPUNORMX-02
**Status:** Planned
**Wave:** 1

## Objective

Represent `LAYER_NORM` and `RMS_NORM` as backend-neutral lowered GPU sub-DAGs with explicit normalized axes, epsilon, output shape, and parameter broadcast contracts.

## Tasks

1. Add the minimal scalar primitive needed for normalization, expected as `AcceleratorDagNodeType.ADD_SCALAR`, with a stable ABI code after the existing Phase 23 reduction codes.
2. Extend `AcceleratorSubgraphLowerer` with a specialized normalization DAG builder:
   - `LAYER_NORM`: repeated keep-dims `MEAN`, `SUB`, `MUL`, repeated keep-dims `MEAN`, `ADD_SCALAR`, `SQRT`, `INV`, `MUL`, `MUL`, `ADD`.
   - `RMS_NORM`: `MUL`, repeated keep-dims `MEAN`, `ADD_SCALAR`, `SQRT`, `INV`, `MUL`, `MUL`.
   - Repeated means reduce trailing axes from last axis down to `rank - normalizedRank`.
3. Validate lowering preconditions before returning a DAG:
   - input dtype `FLOAT32`,
   - input rank 1-4,
   - normalizedRank between 1 and input rank,
   - gamma and beta ranks equal normalizedRank,
   - gamma/beta shape equals input trailing normalized shape,
   - output shape equals input shape.
4. Update lowered-region manifest output so original normalization op maps to multiple primitives and includes a normalization/fused subpattern summary.
5. Add lowerer tests for layer norm, RMS norm, epsilon scalar metadata, repeated keep-dims reductions, gamma/beta external inputs, and unsupported normalized-rank/shape rejection.

## Acceptance Criteria

- `AcceleratorDagNodeType` contains `ADD_SCALAR` with a stable ABI code.
- `AcceleratorSubgraphLowererTest` contains positive tests for `LAYER_NORM` and `RMS_NORM` lowered primitives.
- Lowered `LAYER_NORM` DAG contains at least `MEAN`, `SUB`, `MUL`, `ADD_SCALAR`, `SQRT`, `INV`, and `ADD`.
- Lowered `RMS_NORM` DAG contains at least `MEAN`, `MUL`, `ADD_SCALAR`, `SQRT`, and `INV`.
- Unsupported normalization shapes return `null` lowering rather than planner-supported incomplete DAGs.

## Must Haves

- GPUNORMX-01: normalization lowers to a GPU-resident sub-DAG under the shared Metal/CUDA contract.
- GPUNORMX-02: epsilon and gamma/beta shape semantics are encoded before backend admission.

## Threat Model

- **Threat:** Incorrect broadcast semantics silently produce wrong normalized values.
  **Mitigation:** Shape/rank checks happen before lowering and tests assert external parameter shapes.
- **Threat:** Scalar epsilon gets lost across FFM because it is not represented in the ABI.
  **Mitigation:** `ADD_SCALAR` carries epsilon in `scalarValueBits` and has explicit lowerer tests.
