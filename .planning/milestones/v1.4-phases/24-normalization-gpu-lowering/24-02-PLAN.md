# Plan 24-02: Native Normalization Primitive Execution

**Phase:** 24 Normalization GPU Lowering
**Requirements:** GPUNORMX-01, GPUNORMX-02
**Status:** Planned
**Wave:** 2
**Depends on:** 24-01

## Objective

Make Metal and CUDA execute the normalization sub-DAG primitives natively for supported dense `FLOAT32` rank 1-4 regions.

## Tasks

1. Add Metal MPSGraph execution for `ADD_SCALAR` using a `MPSDataTypeFloat32` scalar constant and `additionWithPrimaryTensor:secondaryTensor:`.
2. Confirm Metal graph execution handles the normalization sub-DAG with MPSGraph broadcasting for keep-dims reductions and gamma/beta tail parameters.
3. Extend CUDA native executable node metadata to track input1 rank, dims, and element count in addition to input0 metadata.
4. Add CUDA dense/broadcast kernels for the normalization-required primitives:
   - `SUB`
   - `MUL`
   - `DIV` if shared binary path needs it
   - `SQRT`
   - `INV`
   - `ADD_SCALAR`
   - existing `ADD` with suffix broadcast support
5. Implement suffix-broadcast index mapping for binary CUDA kernels:
   - input rank may be lower than output rank,
   - aligned dimensions must be `1` or equal to output dimension,
   - unsupported broadcast metadata returns a stable native failure reason before kernel launch.
6. Add capability-gated native tests:
   - Metal explicit shim executes layer-norm-like sub-DAG with output parity.
   - CUDA native path compiles with new kernels when `nvcc` is available; portable Java tests assert stable unavailable behavior when CUDA is absent.

## Acceptance Criteria

- Metal native shim switch handles `ADD_SCALAR`.
- CUDA native shim no longer reports `CUDA buffer execute supports RELU, ADD, and dense FLOAT32 forward reductions.` for normalization-required supported primitives.
- CUDA buffer execution supports dense rank 1-4 `SUB`, `MUL`, `SQRT`, `INV`, `ADD_SCALAR`, and broadcasted `ADD`/`MUL`.
- Unsupported CUDA broadcast shapes produce a stable reason string containing `unsupported broadcast`.
- `metalTest` passes on a machine with Metal shim support.

## Must Haves

- GPUNORMX-01: backend execution exists for the lowered normalization sub-DAG.
- GPUNORMX-02: suffix broadcast and epsilon semantics match CPU-compatible shapes.

## Threat Model

- **Threat:** CUDA reports supported lowering but native execution rejects an internal primitive.
  **Mitigation:** Add kernels before coverage rows move to supported and assert stable native failure reasons.
- **Threat:** Broadcast index math reads out of bounds.
  **Mitigation:** Validate each broadcast dimension before launch and compute indices from output coordinates with rank bounds.
