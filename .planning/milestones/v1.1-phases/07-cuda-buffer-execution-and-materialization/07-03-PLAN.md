    - Binding layout dataType, shape, strides, storageOffset, and logicalElementCount match the requested input layout.

    - Assert `context.requireCpuReadable(middleNodeId, CPU_CONSUMER)` is not called between regions.
    - Assert legacy tensor-array `execute(...)` is not called for either region.

    Add negative tests:
    - `adjacentCudaRegionRejectsDifferentBackendBinding`
