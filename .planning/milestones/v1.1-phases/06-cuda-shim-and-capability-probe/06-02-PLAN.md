<threat_model>
T-6-04: ABI mismatch could be hidden by generic `isAvailable=false`. Mitigation: capability codes distinguish missing library, missing required symbol, shim unavailable, context unavailable, graph ABI unavailable, and buffer ABI unavailable.
T-6-05: CUDA buffer support could be overreported. Mitigation: `supportsBufferBindings()` derives from explicit required buffer symbols and remains false until Java/native buffer execution is implemented.
T-6-06: Runtime availability checks could crash machines without CUDA. Mitigation: all bridge methods return unavailable records or nonblank diagnostics unless execution is incorrectly invoked directly.
</threat_model>
